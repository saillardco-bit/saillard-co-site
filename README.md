# Saillard & Co – site complet

Dossier prêt à publier sur GitHub Pages.

## Publication
1. Ouvrir le dépôt GitHub `saillard-co-site`.
2. Supprimer/remplacer les anciens fichiers par le contenu de ce dossier.
3. Vérifier que `index.html`, `assets/`, les pages de service, `robots.txt` et `sitemap.xml` sont bien à la racine.
4. GitHub Pages republiera ensuite le site.

Le formulaire utilise FormSubmit et envoie les demandes vers saillard.co@gmail.com.
